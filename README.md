ملف SQL مخصص لتهيئة قاعدة Awn فارغة، وليس للتشغيل فوق قاعدة قائمة. لا يتضمن هذا المستودع بيانات الطلاب الفعلية أو نسخ قواعد البيانات أو ملفات التطبيق.
